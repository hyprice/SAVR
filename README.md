# SAVR Android v0.1

A native Android starter project for the SAVR savings tracker.

## Features
- Jetpack Compose UI with a dark liquid-glass visual direction.
- Spring-based bouncy touch feedback and animated page/balance transitions.
- Local Room database for transactions.
- Deposits, withdrawals, balance calculation, transaction history.
- Editable savings target.
- Offline-first; no account, analytics, or network permission.

## Build an APK
1. Install Android Studio (a recent stable release) and Android SDK Platform 35.
2. Extract this project.
3. Open the `SAVR_Android` folder in Android Studio.
4. Let Gradle sync and download dependencies.
5. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
6. The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

Minimum Android version: Android 8.0 (API 26).

This environment did not contain Android SDK/Gradle, so no APK has been compiled or signed here.
